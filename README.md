<details>
<summary><b>🔍 Why Semantic Search vs Keyword Search</b></summary>

<br/>

| Query | Keyword Search | Semantic Search |
|-------|---------------|-----------------|
| `"invoice"` | Returns docs with the exact word "invoice" | Returns docs about billing, payments, receipts |
| `"slow response"` | Returns docs with "slow response" literally | Returns docs about latency, performance, timeouts |
| `"how do I cancel"` | Returns docs with exact phrase | Returns cancellation policy, refund process, account deletion |
| `"Python async code"` | Exact match only | Returns asyncio, coroutines, await patterns |

**Result:** Semantic search finds what users *mean*, not just what they *typed.*
Built with sentence-transformers + Qdrant + PostgreSQL FTS + Reciprocal Rank Fusion.

## 🔬 Engineering Studies

Focused studies isolating specific problems in LLM infrastructure — streaming, agentic tool-use, cost accounting, and provider architecture. Smaller in scope than the live projects above, each is a working, runnable repo with its own README.

| Study | What it proves | Stack |
|-------|-----------------|-------|
| **[Claude Tool-Use Loop](https://github.com/Fuad-Haque/anthropic-tool-use-loop)** | Full `tool_use` round-trip — Claude requests a function call, a real subprocess + grep executes it, result loops back until a final answer | FastAPI · Anthropic SDK · Python |
| **[Context Window Auto-Summarisation](https://github.com/Fuad-Haque/context-window-auto-summarisation)** | Real token counts via Anthropic's `count_tokens` endpoint trigger summarisation at an actual 80% threshold, not an estimate | FastAPI · Python · Anthropic API |
| **[Token Economics & Cost Tracking](https://github.com/Fuad-Haque/token-economics-cost-tracking)** | Four-bucket cost accuracy — input, output, cache-write, cache-read priced separately, checked against Anthropic's own example | FastAPI · Python · SQLite · Anthropic API |
| **[Token Threshold Guard](https://github.com/Fuad-Haque/token-threshold-guard)** | Predicts token count before any API call and blocks over-threshold requests before the network is touched — exact counts via `tiktoken` where possible, labeled approximation where not | FastAPI · Python · tiktoken |
| **[Structured Outputs (Groq)](https://github.com/Fuad-Haque/structured-outputs-groq)** | Schema-constrained JSON extraction across 10 varied real-world inputs — `strict: true` makes an invalid shape structurally impossible to emit | Python · OpenAI SDK · Groq |
| **[Zod Runtime Validation — AI Ticket Triage](https://github.com/Fuad-Haque/zod-validation)** | Three validation gates on one request path — form input, Claude's raw output, and the merged record — each independently schema-checked before the next step | Express · Zod · Claude SDK |
| **[OpenAI Stream (FastAPI)](https://github.com/Fuad-Haque/openai-stream-fastapi)** | Token-by-token SSE streaming that detects client disconnects mid-generation and closes the upstream call immediately, instead of burning quota on a dead connection | FastAPI · OpenAI SDK · Groq |
| **[Anthropic SSE Streaming](https://github.com/Fuad-Haque/anthropic-sse-streaming)** | Every Anthropic stream event handled explicitly, non-blocking SDK calls via `run_in_executor`, and four distinct error states (credential, API, network, disconnect) instead of one generic failure | FastAPI · Anthropic SDK · asyncio |
| **[SSE Reconnect Demo](https://github.com/Fuad-Haque/sse-reconnect-demo)** | Client reconnects send `Last-Event-ID`; the server resumes the stream from that point instead of restarting at zero | FastAPI · sse-starlette |
| **[Route Handlers vs Suspense Streaming](https://github.com/Fuad-Haque/rh-suspense-verify)** | Isolates two Next.js streaming mechanisms that get conflated in conversation — a raw `ReadableStream` Route Handler for non-React consumers, and `<Suspense>` streaming rendered React output into an already-loading page | Next.js · React · TypeScript |
| **[useChat Streaming Chat](https://github.com/Fuad-Haque/usechat-straeming-chat)** | Hand-constructs the Vercel AI SDK's UI Message Stream protocol from a Python backend — no official Python SDK, no Node dependency, `useChat` on the frontend still just works | FastAPI · Next.js · `@ai-sdk/react` |
| **[Vercel AI SDK Streaming Patterns](https://github.com/Fuad-Haque/vercel-ai-sdk-streaming-patterns)** | `generateText`, `streamText`, and schema-constrained structured output isolated into three independent routes, so the difference between them is runnable, not just described | Next.js · Vercel AI SDK · Zod |
| **[Provider Adapters](https://github.com/Fuad-Haque/provider-adapters)** | One `/chat` endpoint routes to OpenAI, Anthropic, or any OpenAI-compatible server — switching providers is an env-var change, zero code changes | Express · Vercel AI SDK |
| **[Tenacity Backoff & Retry Isolation](https://github.com/Fuad-Haque/tenacity-backoff-fastapi)** | Exponential backoff with jitter against a simulated rate-limited API, plus four deliberate misconfigurations that each isolate one retry parameter failing | Python · tenacity |

<details>
<summary><b>🔍 Why Semantic Search vs Keyword Search</b></summary>

<br/>

| Query | Keyword Search | Semantic Search |
|-------|---------------|-----------------|
| `"invoice"` | Returns docs with the exact word "invoice" | Returns docs about billing, payments, receipts |
| `"slow response"` | Returns docs with "slow response" literally | Returns docs about latency, performance, timeouts |
| `"how do I cancel"` | Returns docs with exact phrase | Returns cancellation policy, refund process, account deletion |
| `"Python async code"` | Exact match only | Returns asyncio, coroutines, await patterns |

**Result:** Semantic search finds what users *mean*, not just what they *typed.*
Built with sentence-transformers + Qdrant + PostgreSQL FTS + Reciprocal Rank Fusion.

</details>
